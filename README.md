# coffee-site

Сайт кофейни «Зерно». Мой первый семантический проект.

## Что использовал
- HTML: `<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, `<footer>`
- `<details>` / `<summary>` — для FAQ
- `<hr>` — линии между блоками
- Списки, ссылки

## О чём сайт
Про кофейню: меню, мастер-классы, контакты.
